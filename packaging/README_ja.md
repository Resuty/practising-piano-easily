# practising piano easily

MIDI 鍵盤と交互練習で、音名・コード・読譜を自分のペースで学ぶ Windows アプリです。

## 起動

ZIP をすべてローカルに展開し、`practising-piano-easily.exe` を実行してください。Windows 10 / 11 x64 向けです。Python のインストールは不要です。`_internal` フォルダーを EXE と一緒に保持してください。

初回は日本語で起動します。右上で日本語・简体中文・English を切り替えられます。配布版は未署名のため、実行環境のセキュリティポリシーに従ってください。

## 試してみる

1. 「入門レッスンと楽譜」で第 1 課を選び、楽譜を試聴します。MIDI 鍵盤がなくても画面の鍵盤で試せます。
2. 「コード練習」で目標を確認し、音を一つずつ足します。正しい鍵盤を保ったまま、余分な音を修正できます。
3. 「落下ノーツ練習」で内蔵曲の全曲デモを再生し、楽譜とノーツの同期を確認します。通常の練習区間は 4 小節です。
4. 「コード入門」で構成音と鍵盤例を確認します。演奏画面のコード名から解説に移動し、Esc で元の位置へ戻れます。

左右の切替、区間の繰り返し、練習前のデモ、拡大率と段の密度も設定できます。通常の演奏音は MIDI 鍵盤の音源、試聴とデモはアプリの簡易合成音を使用します。

## データ

新規の練習記録・設定・読み込み曲は `%LOCALAPPDATA%/practising-piano-easily/` に保存します。既存のインストールは以前の保存先を使う場合があります。配布 ZIP に利用者の記録やダウンロード曲は含みません。

## 制約と資料

音高・オクターブが中心で、リズム・保持時間・運指・表現は採点しません。MIDI 生成譜と手の推定は原譜の完全復元ではなく、PDF 単体の音符認識も行いません。

`Source` にソースと設計文書、`THIRD_PARTY` に依存ライブラリのライセンスがあります。外部楽譜の利用には原サイトの条件が適用されます。検証の範囲は `VERIFICATION.md` を参照してください。
