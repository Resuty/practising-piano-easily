# practising piano easily

完整解压后双击 `practising-piano-easily.exe`，无需安装 Python。适用于 Windows 10/11 x64。必须保留同目录的 `_internal` 文件夹。

首次默认日文，右上角可切换日本語、简体中文和 English。可以从新手课程、和弦练习、下落式练琴或乐谱练习开始；没有 MIDI 键盘时，也能点击屏幕琴键试用。

包含 24 节课程、12 首练习曲、10 章和弦教程、听力与和声练习。支持 MIDI 导入、左右手分练、四小节选段、可选演示和反复。正常跟弹音色来自键盘，内置试听使用简易合成音。

包内的 `Source` 是源码，`THIRD_PARTY` 是第三方许可说明。不含个人练习记录、下载曲谱、音源、账号配置或 Git 历史。

新安装数据保存在 `%LOCALAPPDATA%/practising-piano-easily/`。旧安装可能继续使用原数据位置，以保留记录。

目前主要检测音高和八度，不评节奏、保持时长、指法或音乐表现。不做 PDF 光学识谱。外部资源需遵守原站许可。程序未签名，请遵守运行环境的安全策略。验证范围见 `VERIFICATION.md`。
