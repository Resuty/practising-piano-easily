# Supported scope

## Implemented

- Spelling-aware notes, intervals, scales, chord parsing and harmonic analysis
- MIDI chord practice with correction feedback and release-aware progression
- Beginner lessons, repertoire, offline chord tutorials and self-check questions
- Score practice and falling-note practice with a shared MIDI timeline
- Four-bar passages, optional demonstrations, looping and left/right practice
- Ear training, voice-leading measurements and progression MIDI export
- Local MIDI import, optional PDF reference and permission-aware score sources
- Local progress/settings persistence and Japanese/Chinese/English UI
- Windows x64 packaging and data-free source exports

## Current limitations

- No rhythm, fingering, expression or acoustic-piano microphone assessment
- No optical recognition of notes from PDF or scanned sheet music
- MIDI notation and hand assignment are practice-oriented approximations
- Chord/key candidates are heuristic references, not definitive interpretations
- Online resources depend on each site's current permissions and availability
- Physical devices and clean-machine configurations require separate validation

Feature changes should retain the theory, storage and practice contracts documented in the other design files.
