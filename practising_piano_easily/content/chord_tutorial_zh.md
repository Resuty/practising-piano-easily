# 01 开始：把一个和弦真正学会

你看到谱面上的 C，能否说出它有哪些音、在琴上找到它，再听出它与 Cm 的区别？这份教程会从这一件小事开始，把和弦符号、音名、琴键位置、声音和歌曲中的作用慢慢连起来。你不需要先会读五线谱，也不需要一口气学完全部章节。

## 先试一遍 C

在示例区选择 C。软件会显示 C4 E4 G4：数字是八度编号，用来区分低处和高处的同名音，C4 是这里采用的中央 C 编号。点击“播放示例”，先听三个音同时响起的声音；再选 Cm，听 E 降到 Eb 后声音有什么变化。初次听不出来很正常，可以先只比较两个示例，不急着做混合耳训。

点击“练习这个和弦”，会进入和弦练习的“学习”模式，目标就是刚才选中的和弦。没有外接键盘时，点击屏幕琴键可以逐个按下，点第二次松开。三个音同时保持按下后，等待约 300 毫秒，程序才评分。不要把“先后点击”误解成音阶练习：这时需要最终同时按住组成音。

有 MIDI 键盘时，先去 MIDI 监视器选输入设备。按一个键，看看音符和力度是否出现。键盘本身的声音与软件耳训播放是两条途径：MIDI 传递演奏信息，不直接传递录音。当前和弦评分看实际按住的键；即使踏板让声音继续延长，松开的键也不算仍被手按住。

## 每次练习只解决一个问题

建议第一次只读到大小三和弦。用 15 分钟完成一轮：认键和说音名 3 分钟，慢弹 C、Cm、F、Am 5 分钟，比较大小三和弦的声音 4 分钟，最后回看错误 3 分钟。说不出音名就回认键部分；音名对但弹错键，就慢慢找位置；音都对却判错，检查最低音是否符合原位要求。

“学习”模式给提示，“练习”模式先自己回忆再看反馈，“测试”模式不显示答案提示。读完一章可以标记已读；这只表示读过，不代表你已经掌握。要判断掌握程度，可以隔一天不看答案，再说出组成音并弹奏。下方自测先选答案再提交，解析会在提交后出现。

本教程用通行的英文字母音名和和弦符号。按钮和解释可以用中文，但 C、Cm、F#、Bb、V7 这些符号保留原样，方便以后阅读真实谱面。

# 02 认键：为什么 E 到 F 只有半音

先在琴上找到一组“两颗黑键”。紧挨着它们左侧的白键是 C，向右的白键依次是 D、E；接下来“三颗黑键”左边的白键是 F，再向右为 G、A、B，之后回到下一个 C。先认黑键的分组，再找白键，比从琴的最左端一路数过来更容易。

## 一步到底有多远

半音是钢琴上相邻两个键之间的距离，无论黑键还是白键。例如 C 到右边黑键 C# 是一个半音，C# 到 D 又是一个半音；所以 C 到 D 是两个半音，也叫全音。E 到 F、B 到 C 之间没有黑键，它们已经是相邻的键，因此只有一个半音。

符号 # 表示把原来的音升高一个半音，b 表示降低一个半音。F# 是 F 右边相邻的键，Bb 是 B 左边相邻的键。这里的 b 是降号的键盘输入写法，不是另一个字母音名。你也会在谱面看到排版形式 ♯ 和 ♭。

在通常的十二平均律钢琴上，C# 和 Db 落在同一个键，但名称描述了不同的理论关系。这叫等音：声音相同，不代表写法在任何地方都可任意交换。比如 F 大调按 F G A Bb C D E 排列，用 Bb 可以让七个字母各用一次；写成 A# 就重复了 A、漏了 B。

## 用两个检查法找对音

先找 C，再按 C–D–E–F–G–A–B–C 的白键顺序慢弹。每按一次都说出音名。然后只弹 E–F 和 B–C，观察它们之间确实没有黑键。最后找 F# 和 Bb：先定位原来的 F、B，再移动一格，不要凭黑键大概在哪儿猜。

示例 C 的三个目标音是 C E G。根音 C 不变时，换一个八度弹 C E G，仍然可以构成 C 和弦；换八度改变了具体音高，却没有改变音名所属的音级类别。以后软件谈 pitch class 时，指的就是不区分八度的这一层。

如果你的琴把中央 C 标成 C3 或 C5，先看实际声音和 MIDI 编号。不同设备的八度标签可能不同，本软件按 MIDI 60 = C4 显示；不要因为标签差一组就把实际同一个键认成错误的音高。

读完这一章，你应能在不同位置找到 C、F、F#、Bb，并解释 E–F 为什么不是全音。然后做下方自测，检验你是否把“每两个白键之间都是全音”这个误解排除了。

# 03 音程：先数名字，再量距离

构建和弦时，经常要做“从 F# 往上找大三度”这样的任务。如果只记 C–E 的手形，一换根音就容易出错。音程是两个音之间的关系，它有两部分：字母隔了几度，以及实际相隔多少半音。

## 从 C–E 推出大三度

先只数字母，包含起点和终点：C 是一、D 是二、E 是三，所以 C 到 E 属于三度。再沿所有琴键数移动次数：C→C#→D→D#→E，一共四次，就是四个半音。四个半音的三度叫大三度。C→Eb 仍跨 C D E 三个字母，但只有三个半音，所以叫小三度。

把同样的方法用到 F#。要找三度，字母依次是 F、G、A，终点一定是某种 A。再从 F# 向上走四个半音，落到 A#，所以答案写 F#–A#。虽然 Bb 在同一个键上，却不是这里正确的三度拼写。

| 音程 | 半音数 | 从 C 向上的例子 |
| --- | --- | --- |
| 小二度 / 大二度 | 1 / 2 | Db / D |
| 小三度 / 大三度 | 3 / 4 | Eb / E |
| 纯四度 / 纯五度 | 5 / 7 | F / G |
| 小六度 / 大六度 | 8 / 9 | Ab / A |
| 小七度 / 大七度 | 10 / 11 | Bb / B |
| 纯八度 | 12 | 高一个八度的 C |

看表时，把中间列当作声音距离，右列当作从同一根音出发的具体示范。不要直接把“大”理解成响声大：大三度和小三度在这里描述的是音程宽度，不是力度。

## 同一个键也会有不同名字

C–D# 与 C–Eb 都有三个半音，但前者跨两个字母 C D，叫增二度；后者跨三个字母 C D E，叫小三度。类似地，F# 与 Gb 可以在同一个键上，但分别参与不同的音程拼写。六个半音常叫三全音；按字母距离又可能是增四度或减五度。

实际练习时，先慢弹 C–E，再把 E 降为 Eb，最后换成 F#–A#。说出“根音、终点音名、半音数”，比只记两个手指张多开更容易迁移到其他调。乐理练习页的音程构建题要求依次弹起点与终点，最后提交；八度题需要真的弹出两个不同高度的音。

参考：[Open Music Theory：音程](https://viva.pressbooks.pub/openmusictheory/chapter/intervals/)，可用来核对字母距离与半音数的两层判断。

# 04 大小三和弦：差一个音，为什么性质就变了

在 C E G 中，C 是根音，E 是三音，G 是五音。“根音”说明和弦以哪个音为构成基准；“三音、五音”说明它们相对根音的音程位置，并不表示你必须用第三、第五根手指弹。

## 从 C 变成 Cm

C 大三和弦的公式是 1–3–5：根音、大三度、纯五度。从根音起的半音位置是 0、4、7。Cm 的公式是 1–b3–5：把三音降低半音，半音位置变为 0、3、7。所以 C E G 变成 C Eb G 时，只需移动 E，根音与五音都保持不变。

这里的数字公式统一以根音的大音阶作比较基准。b3 是“比该根音的大三度低半音”，不是“把当前调的第三级随便降一下”。一个调的级数与一个和弦的构成公式是两种用途，后面学罗马数字时会再区分。

| 符号 | 组成音 | 从根音起的半音位置 |
| --- | --- | --- |
| C | C E G | 0、4、7 |
| Cm | C Eb G | 0、3、7 |
| F | F A C | 0、4、7 |
| Am | A C E | 0、3、7 |
| D | D F# A | 0、4、7 |
| F# | F# A# C# | 0、4、7 |

第一遍横着读每一行：符号对应哪些音？第二遍只比较 C 与 Cm：变的是哪个音？第三遍比较 C 与 D：半音结构一样，但 D 的三音需要黑键 F#。因此“隔一个白键弹一个”只在某些根音上碰巧有效，不能作为构建任何大三和弦的规则。

## 两种另外的三和弦

减三和弦 dim 是 1–b3–b5，比如 Cdim = C Eb Gb。增三和弦 aug 是 1–3–#5，比如 Caug = C E G#。先在大小三和弦稳定后再加入它们。判断性质时看结构；“大和弦快乐、小和弦悲伤”最多是初听时的印象，速度、旋律、音区和语境都能改变整体感受。

用本页三个示例练习：先弹 C，保持 C 和 G 不动，把 E 降为 Eb，听 Cm；再换成 Am，说出 A C E。右手在舒服的音区可以尝试 1、3、5 指，但这只是起点，指法会随音区、转位和连接方式调整。手腕保持放松，够不到时先缩小任务，不要勉强撑开。

参考：[Open Music Theory：三和弦](https://viva.pressbooks.pub/openmusictheory/chapter/triads/)。完成下方自测后，去和弦练习 Level 1，先保证能正确说音和找键，再考虑速度。

# 05 转位：最低音变了，根音还在

先弹 C4 E4 G4，再弹 E3 G3 C4。两组都只有 C、E、G，都是 C 大三和弦；第二组只是把 E 放在最低处。这说明“根音”不等于“眼前最低的音”。根音决定和弦身份，最低音决定它当前的低音及转位。

## 用整体最低音判断

| 排列例子 | 最低音 | 位置 | 斜线写法 |
| --- | --- | --- | --- |
| C E G | C，根音 | 原位 | C |
| E G C | E，三音 | 第一转位 | C/E |
| G C E | G，五音 | 第二转位 | C/G |

这里按低到高列音。C/E 读作“C 和弦、E 作低音”；斜线右边规定最低音，左边仍然说明 C 和弦。对于七和弦，还有把七音放在最低处的第三转位，如 Cmaj7/B。

一个容易判断错的场景是：右手弹 E G C，左手再弹更低的 C。整个声音的最低音是左手的 C，所以整体仍是原位，不能只盯着右手。反过来，右手用 C E G 的形状、左手弹更低的 E，整体就是第一转位。

## 转位与排列不是同一件事

C3 G3 E4 是跨度较开的排列，但最低音仍是 C，所以仍为原位。加入高一个八度的 C，也只是重复根音，不改变和弦身份。软件按音级检查时允许这种跨八度和重复音；若选择原位，还会额外检查最低音。

所有转位都可以用低音说明，但不是所有斜线和弦都只是转位。例如 C/D 是 C 和弦加上 D 低音，D 不在 C E G 里面，所以不能叫 C 三和弦第一、第二转位。遇到这种写法，先忠实保留指定低音，再结合上下文理解整体和声。

用本页 C/E 与 C/G 示例分别听一次。按“练习这个和弦”时，题目会保留斜线低音要求；即使音名集合正确，最低音错了仍会提示。之后把 C、C/E、C/G 连起来，不急着提速，先在每次落键前说“这次最低音是什么”。

参考：[Open Music Theory：转位](https://viva.pressbooks.pub/openmusictheory/chapter/inversion/)。本章的检查标准是：能看整个低音判断转位，并解释为什么根音没有随低音一起改变。

# 06 七和弦：先分清 maj7、7 和 m7

会弹 C E G 之后，再加入一个 B，就得到 Cmaj7；加入 Bb，则得到 C7。两者只差一个半音，却是不同的七和弦。七和弦通常在三和弦上再叠一个三度，包含根音、三音、五音和七音。

## 先学三种最常见的写法

| 符号 | 构成公式 | C 为根音的例子 |
| --- | --- | --- |
| maj7，大七和弦 | 1 3 5 7 | C E G B |
| 7，属七结构 | 1 3 5 b7 | C E G Bb |
| m7，小七和弦 | 1 b3 5 b7 | C Eb G Bb |
| mMaj7，小大七和弦 | 1 b3 5 7 | C Eb G B |
| m7b5，半减七和弦 | 1 b3 b5 b7 | C Eb Gb Bb |
| dim7，减七和弦 | 1 b3 b5 bb7 | C Eb Gb Bbb |

先只看前三行：maj7 与 7 的三音相同、七音不同；7 与 m7 的七音相同、三音不同。不要把符号里的小写 m 看漏，也不要把没有 maj 的 C7 当成 Cmaj7 的简写。

最后一行的 Bbb 是“重降 B”，在通常钢琴上与 A 同键，但理论上要保留第七个字母 B，再降两个半音。这正是前面把声音距离与音名拼写分开学习的用途。Cm7b5 和 Cdim7 的区别也在七音：一个是 Bb，一个是 Bbb。

## “属七”是结构，也是一个需要语境的词

C7 这个符号确定了 C E G Bb 的结构，但它是否在歌曲里承担属功能，要看所在调和前后和弦。在 F 大调里，C7 是常见的 V7，常引向 F；在其他语境里，它也可以有别的作用。先准确弹出符号，再分析功能，两个问题不要倒过来。

练习时按 Cmaj7→C7→Cm7 的顺序，只移动发生变化的音，分别说出“B 变 Bb”“E 变 Eb”。先同时弹成和弦，再把各音分开听。耳训可以用七和弦性质单项训练；没有掌握其他七和弦时，先在这三个示例之间自行对照。

参考：[Open Music Theory：七和弦](https://viva.pressbooks.pub/openmusictheory/chapter/seventh-chords/)。本章先掌握前三种，再回看半减与减七的差别，不用一次记牢整张表。

# 07 调内和弦：同一套音如何变成 I、ii、V

如果一首歌用 C 大调，能否从 C D E F G A B 直接生成一组可用的基础和弦？可以：从任意一个音开始，每隔一个音取一个，得到该级上的三和弦。这里的“级”是某个音在调内音阶里的位置。

例如从 D 开始，取 D、跳过 E 取 F、跳过 G 取 A，得到 D F A，即 Dm。它从 C 大调第二级出发，所以写 ii：小写表示小三和弦。C E G 写 I，G B D 写 V；减三和弦用小写加 °。

| 级数 | I | ii | iii | IV | V | vi | vii° |
| --- | --- | --- | --- | --- | --- | --- | --- |
| C 大调三和弦 | C | Dm | Em | F | G | Am | Bdim |
| F 大调三和弦 | F | Gm | Am | Bb | C | Dm | Edim |
| F 大调七和弦 | Fmaj7 | Gm7 | Am7 | Bbmaj7 | C7 | Dm7 | Em7b5 |

这张表的价值是“换调后关系仍在”。例如 F 大调的 vi 是 Dm，不是因为 vi 永远等于 Dm，而是 F 大调第六级是 D，从这个级数构建出小三和弦。求 iii7 时，从第三级 A 取 A C E G，所以是 Am7。

## 从级数进一步理解作用

在常见的调性音乐语境里，主功能可以理解为稳定的中心，I 是最直接的例子；属功能常形成向主和弦回归的倾向，V、V7 是典型；ii、IV 常用来准备属和弦，称为属前功能。它们是帮助理解走向的分类，不是每一首歌必须服从的路线。

先慢弹 C–F–G–C，感受离开与回归，再弹 Dm–G7–C。后者常写 ii–V7–I。G7 的 B 到 C、F 到 E 都是半音方向的移动，可以单独弹这两条线，再听完整和弦。不同音乐语境会有别的解决和延续方式，软件因此把调外解释标作“可能”。

在和声分析页选择 F major，输入 Fmaj7 Gm7 C7 Fmaj7，观察 Imaj7、ii7、V7、Imaj7 的对应。接着在进行练习里输入 I V vi IV，先说出 F、C、Dm、Bb 再弹。罗马数字描述调内关系，而 1–3–5 描述单个和弦的构成，请分别使用。

参考：[Open Music Theory：和声入门](https://pressbooks.nebraska.edu/openmusictheory/chapter/intro-to-harmony/)，可进一步阅读主、属前与属功能。

# 08 小调与调外音：E7 为什么能出现在 A 小调

A 自然小调的音是 A B C D E F G。按上一章的方式叠三度，会得到 Am、Bdim、C、Dm、Em、F、G。如果只用这套音，第五级是 Em；但真实音乐里常出现 E 或 E7，然后回到 Am。这不是写错了调。

## 把 G 推近 A

Em 的 G 距 A 两个半音，改成 G# 后距 A 一个半音。这个靠近主音的升高七级音，常称为导音，具有向 A 进行的倾向。因此 E G# B 可以成为 A 小调的强属和弦，加入 D 就是 E7。A 和声小调写为 A B C D E F G#，它展示了这种升高第七级的形式。

实际小调音乐会根据旋律与和声需要使用不同形式，不是整首歌每个 G 都必须升为 G#。Em、G 自然音与 E7 都有可能合理出现。软件的小调基础列表采用自然小调的 i、ii°、III、iv、v、VI、VII；采用大调级数作统一比较的资料，也会将其中 III、VI、VII 写为 bIII、bVI、bVII，要先看记法约定。

## 临时指向另一个和弦

在 C 大调中弹 C–A7–Dm–G7。A7 = A C# E G，C# 不属于 C 大调，但它可以引向 Dm。因为 A7 相当于以 D 为临时目标的属七和弦，所以常解释为 V7/ii，读作“第二级的副属七和弦”。斜线这里连接的是功能目标 ii，和 C/E 里指定低音的用法不同。

另一个例子是 C–Fm–C：Fm 的 Ab 不在 C 大调里，常可理解为从同主音 C 小调借用的 iv，称为调式借用。调外音只是“超出当前调的基础音集”的事实，不等于错误；一个调外和弦也不足以单独证明已经转调。

按本页 Am 和 E7 示例先分别听，再自行弹 E7→Am。接着在和声分析页输入 C A7 Dm G7，查看确定的调内/调外标记与可能解释。你目前只需认识这两种常见来源，不必立刻把副属、借用和更复杂的替代和弦都加入日常随机题。

参考：[SUNY Geneseo：小调的不同形式](https://milnepublishing.geneseo.edu/fundamentals-function-form/chapter/16-minor-scale-variants/)。重点读懂为什么小调的第七级会随语境变化。

# 09 加音、挂留与扩展：Cadd9 为什么不等于 C9

会了三和弦和七和弦之后，许多更长的符号就可以拆开读：根音是什么、基础结构是什么、加入或改变了哪个音。先读结构，再把公式换成音名，避免只凭符号长短判断“高级程度”。

## 三种容易混淆的做法

Csus4 的 sus 表示挂留类结构：以第四音 F 替代第三音 E，所以是 C F G；Csus2 则是 C D G。Cadd9 的 add 表示加音，在 C E G 上加入 D，不删 E，得到 C E G D。C9 则以属七结构 C E G Bb 为底再加 D，所以还包含 Bb。

| 符号 | 组成音 | 要辨认的变化 |
| --- | --- | --- |
| Csus4 | C F G | 四音替代三音 |
| Cadd9 | C E G D | 保留三音，增加九音 |
| C6 | C E G A | 增加六音 |
| C9 | C E G Bb D | 属七结构加九音 |
| Cmaj9 | C E G B D | 大七结构加九音 |
| Cm9 | C Eb G Bb D | 小七结构加九音 |

九音就是越过一个八度的第二音：从 C 数到高处的 D 是九度。同理，十一音对应高处的四音 F，十三音对应高处的六音 A。它们在音级上与 2、4、6 对应，具体放哪个八度则是排列问题。

## 理论完整音与实际排列

C13 理论上可以列 C E G Bb D F A，但实际演奏不要求七种音同时全部按下。音区拥挤、乐队低音分工和旋律都可能让你选择省略；三音 E、小七音 Bb 与十三音 A 往往值得优先关注。不要把这一条当作所有场景唯一正确的配方，也不要从“可以省略”误推成任意少按几个音都成立。软件的练习判定有一套明确的实用省略规则。

变化音用 # 或 b 指定，比如 G7b9 = G B D F Ab；G7#9 = G B D F A#。#9 应写 A#，因为从 G 算九度是 A 类音；虽然 Bb 同键，这里的理论职责不同。先会 G7，再添加并听辨变化，比一次盯着全部字符更清楚。

本页先比较 Csus4、Cadd9、C9。听的时候特别注意：前者换掉 E，第二个保留 E 且没有 Bb，第三个保留 E 并加入 Bb。学会说明这三件事，再进入 Level 5、6；11、13 与变化属和弦可以作为之后的拓展。

参考：[Open Music Theory：和弦符号](https://viva.pressbooks.pub/openmusictheory/chapter/chord-symbols/)，用于查 sus、add 与扩展记号的区别。

# 10 从四个和弦到自己的练习片段

选一个短进行 C–G–Am–F，也就是 C 大调的 I–V–vi–IV。先把每个和弦正确弹出来，再考虑如何从前一个和弦走到后一个。Voice leading（声部连接）关注的是各条音高线怎样移动，而不只是单独每个和弦叫什么。

## 比较两种弹法

第一遍每个和弦都用原位。第二遍尝试下方的具体排列，音从低到高列出；不同八度编号也一并保留，便于直接找键。

| 和弦 | 具体排列 | MIDI 编号 |
| --- | --- | --- |
| C | C3 E3 G3 | 48 52 55 |
| G/B | B2 D3 G3 | 47 50 55 |
| Am | A2 C3 E3 | 45 48 52 |
| F/A | A2 C3 F3 | 45 48 53 |

从第一行到第二行，G3 保留，C3 向下到 B2，E3 向下到 D3。第三行到第四行，A2 与 C3 保留，E3 只向上半音到 F3。你可以先只弹每行最低音，听出低音线，再加上其余音。不要为了数字小而忽略你想表达的旋律与节奏。

把 MIDI 编号按行输入“声部连接”页，软件会显示总移动量、最大跳进和保留的相同音高数。这些是比较方案的客观信息，不是“专业”“好听”的分数。尤其声部数不同时，当前计算只匹配可配对声部，不代表对完整编配进行了艺术评价。

## 把它保存成能继续修改的材料

在编曲工作台依次填入 C、G/B、Am、F/A。先让每个和弦持续 4 拍、速度 80，分析确认无输入错误后导出 MIDI。重新导入到歌曲分析页看音符与候选和弦；同一音集可能有多种解释，例如 C E G A 可以理解成 C6，也可以是 Am7/C。候选分数只是辅助，你仍要结合低音、旋律和前后关系确认。

第一轮不要同时改和弦、节奏、速度、音区。先保持和弦身份不变，只换一个转位，比较前后连接；再保持排列不变，尝试把四拍改成两拍。每次只改变一件事，更容易听见它具体带来什么。

## 一条可以反复使用的练习顺序

先读符号并说组成音，再慢找键，接着关提示回忆，最后用耳朵比较。记录错误时写清是哪一种：根音认错、大小性质混淆、七音漏掉、最低音不符、还是看到级数想不起和弦。下一次练习从具体薄弱点开始，不用每次重读全部教程。

当你能在 C 大调做完这个过程，再把同一个 I–V–vi–IV 换成 F 大调的 F–C–Dm–Bb。边说构成音、边找琴键并比较连接，能帮助你把调内关系应用到不同调性。

后续可沿软件学习阶段进入副属、调式借用、扩展与变化和弦，然后选一首简单歌曲练习“先听低音与变化位置，再检查候选和弦”。每次从一小段出发，保留自己的判断过程。
